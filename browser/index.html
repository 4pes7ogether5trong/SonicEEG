    A field with memory

    Select an EEG application window. Draw the waveform, label and settings regions, then confirm the montage and scales. All image processing and OCR run on this device. No account or cloud AI is needed by this application.

    Live surface shows the latest two-second analysis window. Signed displacement uses the newest reconstructed sample relative to the window mean. Spectral light updates every half second; motion is not a playback of every EEG cycle. Each frequency band occupies a separate translucent surface. Isolate a band to inspect mixed spectra without overlap.

    Whole history places older intervals outward. Side profile spreads them along an axis. Drag to rotate, scroll to approach, or enter the field with WASD and drag. Lens changes perspective; Time expansion opens time around your selection. Section removes an obstructing portion.

    Bright areas indicate amplitude, not abnormality. The prevalence statistic instead shows the fraction of valid time represented by analysis windows at or above your band RMS threshold. It describes the selected amplitude criterion, not seizure burden. Interpolation illustrates montage measurements; it does not estimate cortical sources or connectivity. Empty regions can mean unavailable measurements. Derived connections require a valid graph path. Filter-affected frequency surfaces are hatched in the WebGL view.

    Capture must be running while the source display advances. Hidden, clipped, overlapped or filtered-out information cannot be recovered by zooming. This first extractor supports separated rows and continuous scrolling or a clearly colored sweep cursor; vendor recognition and clinical performance remain unvalidated. The original EEG application remains the source for morphology and clinical interpretation.

    Quantitative history compresses for the overview, preserving peaks, valid duration and gaps. Optional local storage retains the original quantitative frames for detailed time selection; it does not archive waveform screenshots or the original recording. Browser storage can be cleared or exhausted.
